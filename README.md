# QuizFlow Web3 🎓⚡

**AI-Powered Learn-to-Earn & Verifiable Soulbound NFT Credentials (ERC-5192)**

QuizFlow Web3 bridges AI education with decentralized academic credentials and tokenized incentives. Students take dynamic quizzes generated by Google Gemini AI, earn **$QUIZ ERC-20** reward tokens, and mint tamper-proof, non-transferable **Soulbound NFT Certificates (ERC-5192)** directly to their Web3 wallets upon scoring $\ge 70\%$.

---

## 🌟 Key Features

### 1. 🔐 Verifiable Soulbound Credentials (ERC-5192)
- **Non-transferable on-chain NFTs**: Once minted, the credentials are bound permanently to the recipient's wallet address.
- **Dynamic On-Chain SVG rendering**: Visual certificate is generated with vector resolution, displaying the student's address, topic, score, date, and verification status without relying on centralized image servers.
- **Multi-Chain Support**: Compatible with Ethereum Sepolia, Base Sepolia, Polygon Amoy, and Arbitrum Sepolia.

### 2. 🪙 Learn-to-Earn ($QUIZ Utility Token)
- Students automatically earn $QUIZ tokens for demonstrating mastery:
  - **70% – 89%**: 10 $QUIZ
  - **90% – 99%**: 25 $QUIZ
  - **100% Score**: 50 $QUIZ bounty
- Instant claiming flow directly to the connected wallet.

### 3. 🤖 AI Knowledge Engine (Gemini + Local Fallback)
- **Google Gemini 1.5 Flash**: Generate customized quizzes, explanations, and flashcards dynamically on any subject.
- **High-Fidelity Offline Knowledge Base**: Pre-authored datasets across Biology, Chemistry, Physics, History, Literature, and Computer Science so it runs seamlessly even without an API key or internet.

### 4. 📊 Academic Dashboard & Flashcard Hub
- Spaced repetition flashcards with flip-card motion.
- Analytics: streak counter, accuracy rating, difficulty breakdowns, and past exam reviews.

## 🚀 Quick Start

### 1. Run Locally
```bash
npm install
npm run dev
```

Open **[http://localhost:5173](http://localhost:5173)** in your browser.

### 2. Test the Web3 Flow
1. Click **Connect Wallet** in the navbar:
   - Connect **MetaMask** for live on-chain interaction.
   - Or click **Simulated / Demo Wallet** for immediate zero-gas testing.
2. Go to **Study** → Choose a topic and complete the quiz.
3. On the **Results** screen:
   - Click **Claim $QUIZ** to claim your Learn-to-Earn reward tokens.
   - Click **Mint On-Chain Credential** to issue your Soulbound NFT certificate.
4. Head to **Credentials** in the navigation bar to see your verified credential gallery and dynamic SVG vector certificate!
